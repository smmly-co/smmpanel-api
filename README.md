# SMM Panel API

API documentation and integration resources for SMMly.

> **Status: Not released.** The current SMMly application API is unavailable while its implementation is being remediated and verified. This repository does not currently publish a supported endpoint or SDK.

## Scope

This repository is intended to hold:

- A versioned API contract
- Authentication and request-format documentation
- Supported actions, parameters, and response schemas
- Error handling, rate limits, and operational guidance
- Client libraries only after the contract is implemented and tested

## Compatibility

SMMly intends to support familiar SMM V2-style integration conventions where verified. Compatibility must be confirmed against the actual released implementation; do not infer support from conventions alone.

## Release policy

No endpoint, action, SDK, or compatibility claim is supported until it is implemented, tested, reviewed, and documented. Never commit API keys, provider credentials, customer data, or production configuration.

See the [SMMly organization](https://github.com/smmly-co) and [documentation repository](https://github.com/smmly-co/docs).
