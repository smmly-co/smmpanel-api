# SMMly API — Social Media Marketing Panel Integrations

Build reseller and business integrations around SMMly.

The SMMly API is intended for developers, agencies, SMM panel operators and resellers who want to connect their own websites, applications, customer panels, bots and server-side automations to SMMly.

## What integrations are for

- **SMM service catalogue:** connect applications to supported service information.
- **Order creation and tracking:** build customer-facing order workflows around supported API operations.
- **Order status management:** retrieve order information for connected business tools.
- **Reseller panel integrations:** connect your own customer experience to SMMly.
- **Bulk order workflows:** support multi-order operations where available.
- **Business automation:** connect SMMly workflows with your server-side systems.

## API documentation and access

Official API documentation, endpoint details, authentication, supported actions, request and response formats, rate limits and access instructions will be published here when available.

The descriptions above explain the intended integration use cases; they are not a statement that every API operation is currently enabled. Use only the official SMMly API contract published by SMMly.
